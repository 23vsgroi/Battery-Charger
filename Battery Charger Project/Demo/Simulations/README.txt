The Battery charger sim is a complete system simulation for that works for all operating points for both 12V and 24V packs. It include feedback control and an SOC dependent Li-ion equivalent model.

I set up the simulation at the worst case inductor current ripple operating condition.

The LFP model test was a simulation to test the accuracy and feasibility of my Li-ion equivalent model. I used the manufacturers datasheet, discharge tests, and charging tests to get the model accurate.
