The MATLAB simulations were to calculate the worst case component values given operating ranges. 

It calculates the worst case buck converter inductor, buck converter capacitor, and rectifier capacitor values.

For the rectifier capacitor, I choose to make a graph that shows how worst capacitor value changes as generator voltage and
charging current change. This helped me to determine where the charging should begin and at what current that battery should charge.

I made a separate simulation for 12V and 24V packs
